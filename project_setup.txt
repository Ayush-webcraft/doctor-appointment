# Setup Documentation

## Clone The Project
```bash
git clone https://github.com/Ujjalzaman/Doctor-Appointment.git
cd Doctor-Appointment
```

## Install and Run Frontend
```bash
# Install dependencies
npm install

# Setup local environment variables (if any)
# Create a .env file in the root directory and define REACT_APP_API_BASE_URL:
# REACT_APP_API_BASE_URL=https://api.yourbackend.com

# Start development server
npm start
```
